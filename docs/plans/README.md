# 실행 계획

이 디렉터리는 여러 세션이나 여러 변경에 걸쳐 현재 진행 중인 작업의 실행 계획을 보관합니다. 작은 작업의 일회성 계획은 대화나 이슈에 남기고 저장소 문서로 만들지 않습니다.

## 작성 기준

다음 중 하나에 해당하면 실행 계획을 작성합니다.

- 여러 패키지 또는 여러 PR에 걸친 변경
- 단계별 마이그레이션과 호환성 관리가 필요한 작업
- 작업 도중 중요한 선택과 검증 결과를 계속 기록해야 하는 작업

## 필수 형식

```md
# 목표

- Started: YYYY-MM-DD
- Scope: 영향을 받는 패키지와 경로

## 성공 기준

완료를 검증할 수 있는 조건

## 단계

- [ ] 작업과 검증 방법

## 결정 기록

작업 중 선택한 방향과 이유

## 진행 기록

날짜별 결과, 실패, 다음 행동
```

파일명은 `YYYY-MM-DD-short-title.md` 형식을 사용하고 이 디렉터리에 바로 추가합니다. 이 디렉터리에 존재하는 Plan은 진행 중이라는 뜻이므로 별도 `Status`를 기록하지 않습니다.

모든 Plan은 파일명 날짜와 같은 `Started`, `Scope`와 위 네 절을 포함합니다. `Status`, `Closed`와 `종료 결과`는 추가하지 않습니다.

## 종료 정리

작업을 완료하거나 취소할 때 다음 순서로 Plan을 정리합니다.

1. 현재 구조와 정책은 Architecture, 선택 이유와 대안은 ADR, 반복 절차는 Guide로 옮깁니다.
2. 최종 검증 결과와 변경 요약은 해당 PR 또는 커밋 설명에 남깁니다.
3. Plan 파일과 이 인덱스의 행을 같은 변경에서 삭제합니다.

완료·취소 Plan을 위한 `archive`는 두지 않습니다. 실행 과정 자체를 장기간 보존해야 할 별도 요구가 있다면 Plan을 그대로 보관하지 않고 목적에 맞는 문서 유형을 정의합니다. 배경과 트레이드오프는 [ADR 0005](../decisions/0005-keep-only-active-plans.md)에 기록되어 있습니다.
