A pnpm workspace for independently published TypeScript libraries and their build tooling. Package-specific installation, examples, commands, and references live in each package README.

## Published packages

### Libraries

| Package | Purpose |
| --- | --- |
| [`@imhonglu/json-schema`](./libs/json-schema/README.md) | JSON Schema Draft 2020-12 validation with schema-based type inference |
| [`@imhonglu/json-schema-typed`](./libs/json-schema-typed/README.md) | Type-safe JSON Schema definitions and instance type inference |
| [`@imhonglu/format`](./libs/format/README.md) | Strongly typed parsers and formatters for RFC-defined strings |
| [`@imhonglu/pattern-builder`](./libs/pattern-builder/README.md) | Fluent construction of regular-expression patterns |
| [`@imhonglu/toolkit`](./libs/toolkit/README.md) | Reusable TypeScript utility functions and types |
| [`@imhonglu/type-guard`](./libs/type-guard/README.md) | Composable runtime type guards |
| [`@imhonglu/type-object`](./libs/type-object/README.md) | Type-safe wrappers for JavaScript Object APIs |
